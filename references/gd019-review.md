# GD 019 本地全文基准审查

v1.2日常已将本页所述正文、原页图和2026通告编入固定知识包，使用knowledge.py find读取。以下baseline.py和update_review操作保留为v1.1独立PDF来源的兼容说明，不要求固定包每次重新下载、提取或联网。固定包的版本范围写入每份报告；特殊条件及项目事实仍按本页审查关系核实。

基准为用户指定官方页面所链接的《电气电子产品型式认可试验指南》2024 正文。封面编号 GD019-2024，生效日期2024-10-01，共44个PDF物理页。可复用的全文、页面索引和来源快照保存在本地库；项目中使用独立副本，正文哈希必须一致。

公开源代码仅保存官方链接、已核验哈希及导航配置 `references/gd019-2024.json`；不把下载的规范原文或完整提取索引放入公开 Git 仓库/技能 ZIP。本地资料是审查基准，不是对本项目适用性的预先批准。

## 已知的2026年配套通告

CCS于2026-03-23发布[UR E10 Rev.10型式认可试验规程技术通告](https://www.ccs.org.cn/ccswz/specialDetail?id=202603230333226752&type=1)，要求达到其申请日期条件的设备将2024版指南与该通告结合使用。触发日期为CCS收到相关认可申请文件的日期，以2026-01-01为界；涵盖新设备类型、实质性修改后的重新申请及过期证书更新所列情形。不得使用厂家大纲日期、报告日期或简单的“现行年份”替代。

在project.ccs_received_date记录YYYY-MM-DD日期，并记录approval_application_type及日期证据。下载通告官方原文并登记为独立source `CCS-UR-E10-REV10-2026`，读清倾斜试验修订及船型关联要求。update_review.known_updates记录applies或not_applicable、具体理由和通告原文anchor；缺日期、缺通告或结论与日期边界不符，工具保留待核实。已知通告目录不是完整更新清单，每个项目仍须继续检索后续修订。

## 会改变审查结论的关系

- **范围先行**：先读1.1，确认是否属于本指南及是否应按第4章分流；未涵盖设备须补查相应CCS规范/标准。
- **环境与设备双维度**：1.3.3要求同时按表1.3.3a和1.3.3b确定项目。环境A–E与设备类型分别记录。不得只取一列或把两张表简单取交集/并集来代替解释。
- **脚注与续页不可丢**：两张表均跨页；必须读PDF第6–8页。倾斜/摇摆、恒定湿热、盐雾、滞燃等项目的条件须按对应注释解释；有冲突或设备条件不明时待核实。
- **两个A不是一回事**：环境A是安装环境分类，性能判据A是性能要求。不能从“A类环境”推导所有试验都采用性能判据A，或反向推导。
- **审查大纲以外的条件**：按1.3.4–1.3.7核对大纲审批、试验顺序、受试设备一致性及重新校准等安排。
- **引用标准版本**：1.3.8对IEC标准更新/替换有一般使用最新版本的规定。项目有其他适用约束时说明依据；不要把“必须固定原指南引用版次”写成通用规则。引用标准正文拿不到时，相应细节列缺口。
- **替代与免除有条件**：按1.3.3后的说明及1.3.9检查CCS同意、对象、试验和条件；仿真/计算/同类对比材料不因厂家提交就自动等同于获准替代。
- **试验机构及发射要求**：读1.3.10和1.3.11，不能因总表理解而漏掉机构要求或3.2/3.3相关发射要求的适用性检查。
- **其他CCS明文规定**：1.3.12处理其他相关规范/指南与本指南不符或未涵盖的情形。查明具体文件和适用性，不机械以“更严”合并要求。

## 建立一条可追溯意见

先列适用设备、环境、试验项及触发条件，再引用总表相关项、脚注和详细试验条款。参数比对同时检查方法、设备工作状态、监测、时长和结果判据，不能只比数值。多个依据可使用多条 citations，每条保留原文 block_id/quote/page。

`baseline.py search` 返回精确的 block_id、原文和坐标；空白归一化只用于检索，写入 citations.quote 时必须复制返回的原文字串。表格的跨行参数组合必须查看 `page --render` 的PNG及原PDF，不根据逐行提取顺序猜测列关系。
